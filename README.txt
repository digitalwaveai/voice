VOICELINK — ЗАПУСК

В архиве находится само приложение:
- index.html — интерфейс;
- style.css — дизайн;
- app.js — звонки и управление;
- server.js — комнаты по ID;
- package.json — одна зависимость WebSocket.

НА КОМПЬЮТЕРЕ:
1. Установи Node.js, если его ещё нет.
2. Дважды нажми START.bat.
3. Откроется http://localhost:3000

ДЛЯ ОБЩЕДОСТУПНОЙ ССЫЛКИ:
1. Загрузи ВСЕ файлы из этой папки в корень GitHub-репозитория.
2. Подключи репозиторий к Railway или Render как Node.js Web Service.
3. Команда запуска: npm start

GitHub Pages использовать нельзя: он запускает только index.html, но не server.js.
Без server.js комнаты по ID и соединение между друзьями работать не смогут.

Регистрация не нужна. Комната удаляется автоматически, когда выходит последний человек.
